### Engineering Profile & Architectural Focus

Independent systems architect and software engineer with a focus on core Linux user-space architecture, native security sentinels, and low-latency system components. Deeply invested in building memory-safe, verifiable tooling for the **Omarchy Linux** ecosystem, cross-platform Android bridges, and high-performance computational asset workflows.

- **Defensive Systems & Host Security**: Architecting kernel-adjacent monitoring daemons, process group supervisors (`process_group(0)` RAII guards), hardware intrusion traps, honey-token canaries, and strict MAC/DNS privacy shields.
- **Concurrent & Low-Overhead Runtimes**: Writing high-throughput, low-latency services in Rust and C++ with strict zero-allocation hot paths, boundary-checked I/O, and bounded memory caps.
- **Desktop Environments & Shell Frameworks**: Constructing declarative, modular desktop surfaces and telemetry plugins utilizing Quickshell, modern QML, and native IPC bridges.
- **Computational Imaging**: Engineering open-source RAW photographic processors and medium-format negative development pipelines with GPU acceleration and AI integration.
